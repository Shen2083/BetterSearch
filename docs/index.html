Northfield Libraries — catalogue search

A library catalogue searched by meaning. Two versions of the same thing, built from the same 4,000 records and the same model. The only difference is what the reader has to decide.

  • Two search modes →

    The reader chooses: catalogue search, which finds the words you typed, or search by meaning, which finds records about what you asked for. Switching between them on one query is the clearest way to see the difference.

  • One search box →

    No choice to make. Every search goes by meaning, and records you appear to have named — an exact title, an author, a phrase in sequence — are lifted to the top and say why they are there.

Both run entirely in the page: the catalogue, its embeddings and the search itself, with no server. The first search by meaning downloads a ~35 MB model once, then works offline. Keyword matching needs no download at all.

Records are real, from Open Library. Availability, branches and the events programme are invented.
